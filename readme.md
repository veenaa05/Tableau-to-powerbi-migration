# Tableau to Power BI migration

This project aims to migrate Tableau dashboards to Power BI dashboards. It is divided into 3 separate parts: scripts, Tableau files and converted files. The scripts folder contains the core logic, split into modules for each step of the process. Since the Tableau files are expected to be in one folder, the main run script takes in an entire folder as input (`02_tableau_files`) and dumps each dahsboard in the output folder (`03_converted_pbips`), which is not included with this repo as it changes constantly during testing and will lead to more commits than necessary.

## Prerequisites
To install the required packages, create a virtual environment and run

```bash
pip install -r requirements.txt
```

## Configuration
Since the run script requires a connection to a MongoDB database, the following details must be specified in `run_config.json`: 
```json
{
    "DATABASE": "YOUR_DATABASE_NAME",
    "USER_NAME": "YOUR_DATABASE_USERNAME",
    "PASSWORD": "YOUR_DATABASE_PASSWORD",
    "SERVER_IP": "YOUR_SERVER_IP",
    "SERVER_PORT": "YOUR_SERVER_PORT"
}
```

## Running the script
Navigate to the scripts folder and run

```bash
python run.py
```

This will commence the migration process for each dashboard in the input folder.

## Modules
Development for this project aims to follow a modular structure between the different components required for dashboard migration. The entire migration process revolves around a few key components:
- **File validation**: Ingesting input TWB files and verifying whether all the required tags are present in the XML DOM.
- **Metadata and structure parsing**: Input TWB files will be parsed to find:
  - Connections
  - Dashboards
  - Figures (X and Y coordinates, columns, which dashboard they belong to)
  - Data sources and columns
- **Report generation**: The report generation module refers to extracted metadata and generates the `report.json` file for each dashboard.
- **Model BIM generation**: `model.bim` is generated by this module, and it contains data sources and connections.
